# 부산 구·군 경계 데이터

- 원본: `southkorea/southkorea-maps`의 `skorea-municipalities-2018-geo.json`
- 출처: 통계청(KOSTAT) 2018 행정구역 경계 기반 공개 데이터
- 프로젝트 적용: 부산 코드(`21`)의 16개 구·군을 강조하고, 지도 맥락을 위해 인접한 울산·경남 일부 지역을 중립색 배경 경계로 함께 추출
- 원본 저장소: https://github.com/southkorea/southkorea-maps

이 파일은 서비스 시각화와 해커톤 데모를 위한 것으로, 최신 법정 경계나 측량·행정 판단 용도로 사용하지 않습니다.
